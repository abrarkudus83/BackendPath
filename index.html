      HTTP & REST

      Gunakan method sesuai aksi, dan kembalikan status code yang jujur.

      Method Kegunaan Contoh endpoint
      GET Mengambil data /api/todos
      POST Membuat data baru /api/todos
      PUT Mengganti seluruh data /api/todos/1
      DELETE Menghapus data /api/todos/1
      Status Arti
      200 Permintaan berhasil
      201 Data baru berhasil dibuat
      400 Input tidak valid
      401 Belum terautentikasi
      403 Sudah login, tetapi tidak punya izin
      404 Data atau endpoint tidak ditemukan
      500 Kesalahan di sisi server

      SQL dasar

      Empat query yang paling sering dipakai saat membangun CRUD.

      SELECT id, title FROM todos WHERE done = false;

INSERT INTO todos (title) VALUES ('Belajar SQL');

UPDATE todos SET done = true WHERE id = 1;

DELETE FROM todos WHERE id = 1;

SELECT todos.title, users.email
FROM todos
JOIN users ON users.id = todos.user_id;
      • Gunakan parameterized query ($1, ?) untuk mencegah SQL injection.
      • Tambahkan INDEX pada kolom yang sering dipakai di WHERE atau JOIN.
      • Selalu uji DELETE dan UPDATE dengan SELECT lebih dulu.

      Perintah Fungsi

      Express

      Kerangka minimal untuk API Node.js. Urutan middleware penting: body parser dipasang sebelum route yang membutuhkannya.

      const express = require('express')
const app = express()

app.use(express.json())

app.get('/api/todos', (req, res) => {
  res.json([])
})

app.post('/api/todos', (req, res) => {
  const { title } = req.body
  if (!title) {
    return res.status(400).json({ error: 'title wajib diisi' })
  }
  res.status(201).json({ id: 1, title })
})

app.listen(3000)
      • Simpan port dan kredensial di .env, bukan langsung di kode.
      • Kembalikan 400 untuk input tidak valid, bukan 500.
      • Gunakan express.Router() jika route mulai banyak.

      Keamanan dasar

      Checklist minimum sebelum API dibagikan ke orang lain.

      • Hash password dengan bcrypt atau argon2; jangan simpan teks asli.
      • Validasi semua input di server, bukan hanya di front-end.
      • Jangan commit .env; tambahkan ke .gitignore.
      • Gunakan HTTPS di produksi dan rotasi token rahasia secara berkala.
      • Tambahkan rate limit pada endpoint login untuk mencegah brute force.
